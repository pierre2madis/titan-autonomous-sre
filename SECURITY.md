# Security Policy

## Supported Versions

TITAN v0.1.0 is an initial public preview.

It is intended for evaluation, education, and offline
demonstration of evidence-driven SRE causal correlation.

## Security Scope

This preview does not include:

- Production n8n workflows
- Automatic remediation execution
- Production credentials
- PagerDuty or ServiceNow integrations
- Production Splunk or Dynatrace configuration
- Remote command execution services

## Responsible Disclosure

Do not disclose potential vulnerabilities publicly before
they can be reviewed.

Report suspected vulnerabilities privately to the repository
maintainer using GitHub private vulnerability reporting,
if enabled.

Do not include production credentials, private keys,
or sensitive operational data in vulnerability reports.

## Operational Disclaimer

The included components and fixtures have been tested
in a controlled laboratory environment.

They are not certified for unattended production remediation.

Users must independently validate their environments,
security policies, and operational controls.
